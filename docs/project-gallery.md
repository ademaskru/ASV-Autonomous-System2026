
# ASV 2026 — Project Gallery

## 1. Overview

This gallery presents the visual documentation of the
Autonomous Surface Vehicle (ASV) project developed
by Team Varuna, Universitas Brawijaya.

It includes the monitoring dashboard and visual
documentation of the autonomous vessel system.

## 2. ASV Monitoring Dashboard

The web-based monitoring dashboard provides
an interface for observing vessel information,
camera feeds, navigation data, and mission progress.

![ASV Monitoring Dashboard](../Screenshots%20Website%20ASV%202026/dashboard.png)

### Dashboard Features

- Surface camera monitoring.
- Underwater camera monitoring.
- Speed Over Ground (SOG).
- Course Over Ground (COG).
- GPS position and geotag information.
- Vessel trajectory visualization.
- Mission A and Mission B interfaces.

## 3. System Architecture

The ASV software architecture integrates ROS 2,
Pixhawk, GPS navigation, computer vision,
autonomous control, and telemetry communication.

See [System Architecture](architecture.md).
