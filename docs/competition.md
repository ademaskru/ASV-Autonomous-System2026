
# KKI 2026 — Autonomous Surface Vehicle

## Competition Overview

The Autonomous Surface Vehicle (ASV) project was
developed and implemented by Team Varuna from
Universitas Brawijaya for the 2026 Indonesian
Ship Contest (Kontes Kapal Indonesia / KKI 2026).

The project involved the integration of autonomous
navigation, computer vision, embedded systems,
and robotic control for an unmanned surface vessel.

## Technical Implementation

The ASV system integrated several technologies:

- ROS 2 as the robotics middleware.
- MAVROS for communication with Pixhawk.
- GPS-based waypoint navigation.
- Computer vision using YOLO and OpenCV.
- Fuzzy Logic-based control.
- Telemetry data processing and communication.
- Web-based vessel monitoring interface.

## Autonomous System

The software architecture supported different
navigation and mission configurations according
to the competition course conditions.

The system combined perception, navigation,
and control modules to support autonomous
vessel operation.

## Competition Achievement

**Competition:** Kontes Kapal Indonesia (KKI) 2026
